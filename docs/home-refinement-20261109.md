Fire生活首页与消息修正
1. 消息入口在本机缓存异常时仍可打开；页面路由登记在 pages.json；跳转失败有明确提示。
2. 铃铛20px，取消外圈和背景，点击区域仍为44px。
3. 首页模式切换改为32px文字栏与细下划线，不再显示普通等待同步横条；真实错误、登录失效、存档冲突仍可见。
4. 会员有效期统一为“2026年11月12日”格式，不依赖 WebView 的语言支持。
5. 消息缓存增加兼容检查，异常记录不阻断页面。

安装方式：
解压替换包，将“绿岛”中的文件按路径覆盖到项目中。本包包含上一轮界面修改所需文件。
务必一起覆盖 pages.json、pages/messages/index.vue 和 utils/message-navigation.js，然后使用原包名、原证书完整重新打包。
新增消息页面需要完整构建，单独覆盖首页或只加载旧调试基座可能无法注册新路由。
本包不包含APK，不会把未打包版本标成官网已发布，无需替换云函数或改数据库权限。
