更新内容
- 仅替换左上角 Fire生活文字左侧的小 Logo，使用去除黑色背景的透明 PNG。
- 页脚 Fire生活旁的 Logo 同步替换，移除原图标的方形底色、描边与阴影。

上传方法
1. 备份当前官网发布文件夹。
2. 把本包的 index.html、download.html、privacy.html 和 assets 文件夹合并到原官网发布文件夹，覆盖同名文件。
3. 保留原有 fireday.apk、其他安装包、app-update.json 以及其他站点资料，再执行静态网站托管的“更新服务”。
4. assets/fireday-leaf.png 必须保持这个相对路径，不能只上传HTML而遗漏图片。
5. 刷新 fireday.cn，检查页头、页脚的小绿叶和底部“隐私条款”。若看到旧图标，刷新浏览器缓存后再查看。

本包只涉及官网下载网站，不改 App 源码、云函数、签名证书或安装包。
PNG 的外部背景与叶片之间的镂空均为透明通道；不增加黑色或其他底框。官网原有灰色页面背景保持原样。
