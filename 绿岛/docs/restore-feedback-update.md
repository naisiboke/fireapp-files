# Fire生活：恢复快捷记账与加载反馈

本次只落实已确认的五项调整，保留账本里的预算、消费分布、收支明细和原有记录。

1. 记账重新使用原来的“分类网格 → 数字键盘 → 完成”页面。完成后回到分类选择，可继续快速记下一笔。预算仍在记账概览设置，填写预算不会生成收支记录。修改记录和删除确认继续可用。
2. 邮箱登录按钮在真实请求期间显示匀速旋转的圆环和“登录中”，防止重复提交；恢复账号期间继续显示，失败后恢复按钮。验证码保持字符串，保留以 0 开头的验证码；发送倒计时不变。
3. 首页正常同步成功后不显示“已恢复当前账户的数据”这类提示。等待同步、恢复中、失败、登录过期和数据冲突提示仍保留。
4. 社区首次加载、刷新和加载更多使用小圆环。刷新保留已有帖子；失败时停止转圈并保留重试提示。旧请求返回不会误关新请求的加载状态。
5. 首页“自由日／我的目标”改为清晰分段按钮：深绿底白字选中、浅底深字未选中；选中背景平滑移动，倒计时轻柔切换。财务数据和目标日期算法不变。

## 安装更新

- 先备份现有项目，再将更新包内“绿岛”目录中的文件按原目录覆盖到 App 项目。
- 使用原包名和原签名证书，通过 HBuilderX 重新打包 APK 后安装。
- 本次无需部署云函数、创建数据库或更新官网。旧 APK 不会因为源码更新自动改变。
- 这是源码更新包，尚未替你生成或发布签名 APK。

## 按这五项验收

1. 打开记账，点加号：应看到原来的分类选项。选餐饮、输入 30、点完成，再记一笔工资。返回概览确认支出、收入、预算和占比各自正确；修改、取消删除、确认删除也要可用。
2. 邮箱获取验证码后登录：按钮应立即出现圆环，大小不跳动。错误验证码恢复可重试，正确验证码进入首页；可用以 0 开头的验证码检查完整性。
3. 正常登录返回首页：冗余的恢复成功提示应消失，原资产和目标仍在。同步异常时仍有处理提示。
4. 进入社区和刷新：应看到小圆环。刷新期间帖子保留，网络失败时圆环停止并提供重试。
5. 在自由日和我的目标之间切换：选中项一眼能认出，显示内容随之变化，目标日期及资产不会被改写。

原替换版尚未提交的新增记账输入，会在同一账号、同一月份转交到原记账编辑页。旧版编辑页的账号草稿恢复机制继续保留。

开发验证包含业务回归、原数字键盘保存、登录请求生命周期、社区请求竞争、手机浏览器页面交互、原聚光灯引导回归和 H5 构建。测试使用隔离的模拟账号和 uni 接口，不访问生产账户。最终 APK 的键盘、返回键和真实网络体验仍需真机验收。
