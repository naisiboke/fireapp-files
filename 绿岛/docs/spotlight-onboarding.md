# Fire生活三步聚光灯引导

本次新增首次登录后显示的三步引导：记账 → 填写资料或查看计划 → 工具。

- 遮罩黑色约 70%，镂空连续移动与变形 400ms；细白描边呼吸，白色说明气泡，右上角跳过，最后一步知道了。
- 加号与原有扇形菜单保持原设计。引导会自动展开记账入口，切换到第二步时收回菜单。
- 完成或跳过按账号保存在本机；同账号无需反复观看。在“我的 → 设置 → 重新查看新手引导”可以重看。
- 登录恢复、同步冲突和其他重要弹窗优先。引导不会写入财务资料、任务或经验。
- 旧版五页指南改为兼容跳转，不影响登录恢复原页面。

## 如何更新与测试

这是源码更新，需要在 HBuilderX 重新打包、安装后才生效。已有 APK 不会因网页源码变化而自动改变。

1. 下载更新包并解压，将包内“绿岛”文件夹中的文件，按同名目录覆盖到原 App 项目中；覆盖前保留一份原项目备份。
2. 使用原来的 Android 包名和原签名证书，在 HBuilderX 重新打正式包，安装测试。
3. 已使用过旧指南的账号不会被强制重看。测试时可从“我的 → 设置 → 重新查看新手引导”进入，无需清空资产记录或重新注册。
4. 检查三步切换、快速点击下一步、跳过、再次进入首页，以及手机旋转和状态栏间距。
5. 本次无需部署云函数或创建数据库；网站、APK下载文件、版本更新通知配置未随此次修改发布。

## 开发验证

- `node scripts/check-spotlight-guide.mjs`：账号隔离、记忆、旧指南迁移、路由和几何布局。
- `node scripts/check-*.mjs` 中的现有回归脚本逐个运行：资产任务、记账、经验、登录恢复等。
- `node scripts/verify-spotlight-browser.mjs`：真实 Vue 引导组件和首页引导逻辑，在 Chromium 的手机视口中验证连续转场、遮罩、跳过、重看、账号切换、重要弹窗暂停及减少动态效果。
- 浏览器测试使用隔离的本地账号与财务展示数据、模拟 uni 接口，不访问生产云端。它不能代替最终签名 APK 的真机验收。
- 工作流还验证 H5 构建。App 端使用 HBuilderX 配套的原生运行时重新打包，本次不生成可安装 APK；请在最终签名 APK 中验收。
