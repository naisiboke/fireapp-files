# Fire生活简约记账与拔草更新

本次按已确认的 390 × 844 设计更新记账、极简拔草页面，并检查小屏、横屏与键盘高度。

## 已完成

- 记账顶部保留“支出预算”和“收入目标”，首次进入未设置的月份时弹出填写面板；以后可从右上角修改。计划额度不会成为真实收入或支出。
- 实际支出、剩余预算和实际收入分别统计；消费分布只统计选中月份的真实支出。支出明细显示内容、分类、金额和占比；收入不计入消费占比。
- 没有记录时显示本地矢量“小账本与笔”，轻微上下浮动；虚线箭头指向加号，加号每隔几秒轻弹。两个可编辑 SVG 插画位于 docs/illustrations。
- 点击加号打开底部输入面板。保存成功后关闭面板、记录飞入列表并轻微回弹，首次添加有小提示。保存失败时保留输入并回滚数据，不播放成功动画。
- 极简拔草使用同一套样式和“小盆栽”插画，保留进行中、挑战成功、已购买三个分类及到期确认流程。每个项目仍可删除，删除前提示无法恢复。
- 页面顶部和滚动后的返回栏均保留状态栏间距。右下角按钮避让底部安全区域；拔草页按钮位于原底部导航上方。
- 返回键先关闭输入面板或确认弹窗，再返回实际来路；直接打开页面时返回工具页。旧版记账编辑链接仍可用。
- 原主页中央加号和扇形菜单保留，记账快捷入口及每日记账任务进入新页面的输入面板。
- 表单草稿纳入原有账号恢复机制，切换账号会清空上一账号尚未提交的输入。任务经验仍按原云端确认机制处理。

## 更新方式

1. 备份当前源码，解压更新包，将其中“绿岛”目录内的文件按原目录覆盖到 App 项目。
2. 使用原包名和原签名证书，在 HBuilderX 重新打包、安装测试。
3. 本次无需部署云函数、创建数据库或修改官网。包名、签名设置和正式发布版本配置未改变。
4. 新版 APK 尚未替你上传官网；现有用户的旧 APK 不会仅因源码更新而改变。

## 测试方法

- 使用没有本月记录的测试账号打开记账页，填写支出预算 3000、收入目标 8000；检查概览仍显示实际收支 0。
- 分别添加支出和收入，检查消费明细、分类占比与剩余预算；修改与删除后应立即更新。
- 打开输入面板并弹出键盘，检查标题、关闭键和添加按钮可用；按返回先关闭面板。
- 在极简拔草中添加、查看、取消删除、确认删除，检查三个状态分类及到期确认仍有效。
- 字体较大或屏幕较小时可滚动表单；系统减少动态效果时停用浮动、弹跳与飞入动画。

开发验证包括原业务回归、金额与保存回滚测试、真实页面的 Chromium 手机视口交互测试、原聚光灯引导回归和 H5 构建。浏览器使用隔离的模拟账号和 uni 接口，不读写生产云端。最终签名 APK 的键盘及返回键仍需真机验收。
