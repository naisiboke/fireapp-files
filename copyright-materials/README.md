1. 功能说明与申请信息参考：有事实依据的技术与功能内容已整理；开发完成日期、发表信息、开发方式和真实硬件配置必须由申请人核实。

3. 源程序鉴别材料：31个业务JavaScript文件按清单汇编，格式化后5039个非空行，取连续前1500和后1500行，按60页、每页50条真实源码排版。代码来自实际项目，不添加空白、重复代码或第三方依赖凑行数。
4. 源码清单与选段映射：记录文件顺序、每页所属文件和汇编行范围。末页以业务模块结束。源程序文件来自现有公开工程，依赖接口名称保留，不将第三方SDK源码作为本人代码。

操作
- 下载 materials-generator.html 并在本机浏览器打开。
- 软件名称与版本已统一；输入著作权人姓名，核对申报事实。
- 上传8张必需的原始截图：邮箱登录、首页、FIRE退休计算、目标储蓄、记账、极简拔草、人格测试、AI对话。资产记录、到期弹窗、社区和设置为可选补充。
- 截图使用同一正式版本，完整显示当前应用界面、功能标题和操作按钮；原始图片保持清晰，避免浏览器边框、其他应用标识、遮挡文字的悬浮通知及个人隐私。
- 未补齐截图时，只生成待补截图稿；资料齐全后再生成提交候选稿，并由申请人及代理核对原模板要求。
- Word打开后复核实际页数、换行、图片比例及页眉页脚，另存PDF再次检查。当前环境无法运行Word/排版引擎，不能保证各种字体环境下零分页差异。
